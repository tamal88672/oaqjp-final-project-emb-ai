Bharatiya Handicrafts

Trade Management Platform — Crafted with Care

A complete web application for managing Indian handicraft exports to the US market.
Product catalog, inventory tracking, supplier management & business reporting.

React 19 Express.js SQLite Tailwind CSS REST API
💼 Business Needs Solved

This platform addresses every stage of the India-to-US handicraft trade pipeline.

🛍️

Product Showcase for Suppliers

Present your full handicraft catalog to Indian suppliers and artisans. High-quality images, detailed descriptions, and organized categories make it easy to say "these are my products." Suppliers can see exactly what you're trading.

📦

Inventory & Stock Control

Track stock levels in real time. Get low-stock alerts before you run out. Every quantity change is logged with timestamps so you always know what moved and when — critical for export planning.

🏷️

Dual Currency Pricing

Manage both INR cost price (what you pay artisans in India) and USD selling price (what US buyers pay). See margins at a glance. Essential for cross-border trade profitability.

📊

Business Reports & Activity Logs

Full audit trail of every product added, stock adjusted, and change made. Date-filtered activity logs, category-wise breakdowns, and dashboard summaries give you a bird's-eye view of your business.

🤝

Supplier & Artisan Directory

Maintain a searchable directory of all your artisan contacts across India — with specialization, location, and contact details. Build and manage your supply network from one place.

📖

Artisan Stories & Provenance

Capture each product's origin state, artisan name, and their story. US buyers value authenticity and craftsmanship heritage — this feature helps you market products with a compelling narrative.

Why SQLite?

Zero configuration, no separate database server to install, portable single-file storage. Perfect for starting out. When the business grows, the same SQL queries work with PostgreSQL or MySQL with minimal changes.

🔌 API Reference

26 REST API endpoints powering the application.

Categories — /api/categories
MethodEndpointDescription
GET/api/categoriesList all categories with product count
GET/api/categories/:idSingle category with its products
POST/api/categoriesCreate category (multipart image upload)
PUT/api/categories/:idUpdate category
DEL/api/categories/:idDelete (blocked if products exist)
Products — /api/products
MethodEndpointDescription
GET/api/products?category_id=&status=&search=&sort=&min_price=&max_price=List with filters & sorting
GET/api/products/:idFull product details + inventory
POST/api/productsCreate with auto-SKU & inventory init
PUT/api/products/:idUpdate product details
DEL/api/products/:idDelete product + inventory + logs
Inventory — /api/inventory
MethodEndpointDescription
GET/api/inventoryAll stock levels with status (ok/low/out)
GET/api/inventory/alertsLow & out-of-stock items only
PUT/api/inventory/:productIdUpdate quantity & auto-log change
Reports — /api/reports
MethodEndpointDescription
GET/api/reports/summaryDashboard stats: totals, value, alerts
GET/api/reports/activity?from=&to=&product_id=Activity log with date filters (max 100)
GET/api/reports/category-breakdownProducts & total value per category
Suppliers — /api/suppliers
MethodEndpointDescription
GET/api/suppliers?search=List with search across all fields
GET/api/suppliers/:idSingle supplier details
POST/api/suppliersCreate supplier
PUT/api/suppliers/:idUpdate supplier
DEL/api/suppliers/:idDelete supplier
🚀 Quick Start

Get the app running in under 2 minutes.

1

Install Dependencies

Install both server and client packages.

npm install
cd client && npm install
2

Start Development Server

Runs both backend (port 5000) and frontend (port 5173) concurrently.

npm run dev
3

Open in Browser

Visit the app and start adding your products!

http://localhost:5173
4

Production Build

Build the frontend and serve everything from Express.

npm run build
npm run server
Prerequisites: Node.js 18+ and npm installed on your machine. No database server needed — SQLite runs embedded.
